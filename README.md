MerQueueRy is a web-based queue management system for a pharmacy, built with Flask and Jinja2. It lets customers take a ticket for a service (buying a medicine, buying with a prescription, or priority service) and shows each ticket's service and status (waiting, in service, or done) in a live queue list. To run it, install Flask with `pip install flask`, then from the project folder (the one containing `app.py`) run `flask --app app run --debug` and open http://127.0.0.1:5000 in your browser.

The dashboard is currently open. In case staff comes in a week, it can be easily open just by typing the localhost address.

★ Staff Feature: Customer Category Filter. The staff can easily distinguish the priority and regular customers.
